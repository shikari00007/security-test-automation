# Standards

- OWASP Desktop App Security Top 10 (community project; cite as such and note its maturity).
- Electron official security checklist for renderer and IPC guidance.
- OWASP ASVS for authentication, session and cryptographic requirements where applicable.
- Microsoft secure coding guidance for DLL loading and service configuration.
- CWE: CWE-427 uncontrolled search path, CWE-428 unquoted search path, CWE-494 download of code without integrity check, CWE-798 hardcoded credentials, CWE-502 deserialization, CWE-1021 improper restriction of rendered UI layers, CWE-78 command injection.
