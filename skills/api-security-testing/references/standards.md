# Standards

- OWASP API Security Top 10 2023 (API1 to API10 as in methodology). Cite the edition; the 2019 list has different ordering and names.
- OWASP ASVS: API and web service chapter plus authentication, session, access control; cite the ASVS version.
- CWE: CWE-639 (authorization bypass via user-controlled key), CWE-285 (improper authorization), CWE-915 (mass assignment), CWE-347 (improper signature verification), CWE-918 (SSRF), CWE-770 (allocation without limits), CWE-209 (error message information exposure).
- Do not claim compliance; map only where the finding matches.
