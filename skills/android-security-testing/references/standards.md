# Standards

- OWASP MASVS v2 categories: MASVS-STORAGE, MASVS-CRYPTO, MASVS-AUTH, MASVS-NETWORK, MASVS-PLATFORM, MASVS-CODE, MASVS-RESILIENCE, MASVS-PRIVACY.
- OWASP MASTG: test procedures that correspond to MASVS controls; cite the MASTG test when you follow one.
- OWASP Mobile Top 10 (2024 edition exists with updated names; cite the edition).
- CWE: CWE-926 improper export of Android application components, CWE-312 cleartext storage, CWE-319 cleartext transmission, CWE-295 improper certificate validation, CWE-327 broken crypto, CWE-749 exposed dangerous method (JavaScript interface).
