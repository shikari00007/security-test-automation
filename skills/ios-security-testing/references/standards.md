# Standards

- OWASP MASVS v2 categories (STORAGE, CRYPTO, AUTH, NETWORK, PLATFORM, CODE, RESILIENCE, PRIVACY) and the matching OWASP MASTG iOS tests.
- OWASP Mobile Top 10: cite the edition used.
- Apple platform security documentation as the source for Keychain, ATS and entitlement semantics.
- CWE: CWE-312 cleartext storage, CWE-319 cleartext transmission, CWE-295 certificate validation, CWE-926/CWE-939 improper handling of URL schemes and intents (cite only if applicable), CWE-327 broken crypto.
