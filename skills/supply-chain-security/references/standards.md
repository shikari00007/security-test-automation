# Standards

- SLSA (Supply-chain Levels for Software Artifacts): cite version and level; provenance and build isolation requirements.
- OWASP Top 10 A06 Vulnerable and Outdated Components and A08 Software and Data Integrity Failures (2021 edition); OWASP Software Component Verification Standard (SCVS).
- OpenSSF Scorecard checks and OpenSSF guidance for pinned dependencies and token permissions.
- NIST SSDF (SP 800-218) practices; SBOM formats SPDX and CycloneDX.
- CWE: CWE-829 inclusion of functionality from untrusted control sphere, CWE-494 download without integrity check, CWE-1104 use of unmaintained third-party components, CWE-798 hardcoded credentials, CWE-1357 reliance on insufficiently trustworthy component.
